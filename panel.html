      Gotowe prompty

      Backup danych panelu

      Prywatnie: Backup pobiera lokalną kopię danych panelu. Plik jest prywatny — nie wrzucaj go do repo ani nie wysyłaj osobom trzecim.
      Eksport nie zmienia danych i nie wysyła nic poza panel.

      Podgląd backupu JSON

      Uwaga: To jest tylko podgląd. Ten etap nie przywraca ani nie nadpisuje danych.

      Podgląd paczki importu danych

      Uwaga: To jest tylko podgląd paczki importu. Dane nie są zapisywane ani dopisywane do panelu.
      Ten szablon służy do przygotowania paczki danych do późniejszego podglądu/importu. Samo pobranie szablonu niczego nie zmienia w panelu.

      Import dokumentów i cenników

      Bezpieczny import: Import dopisuje wyłącznie dokumenty, cenniki i materiały sprzedażowe do prywatnej listy dokumentów. Nie importuje klientów, ofert, notatek, budżetu, finansów ani checklist.

      Import budżetu startowego

      Bezpieczny import: Import dopisuje wyłącznie pozycje budżetu startowego. Nie importuje klientów, ofert, notatek, dokumentów, cenników, finansów ani checklist.

      Import klientów

      Bezpieczny import: Import dopisuje wyłącznie klientów do CRM. Nie importuje ofert, historii, notatek, dokumentów, cenników, budżetu, finansów ani checklist.

      Import ofert

      Bezpieczny import: Import dopisuje wyłącznie oferty do istniejących klientów. Nie tworzy klientów i nie importuje notatek, dokumentów, cenników, budżetu, finansów ani checklist.

      Import historii / notatek

      Bezpieczny import: Import dopisuje wyłącznie wpisy historii do istniejących klientów. Nie tworzy klientów i nie importuje ofert, dokumentów, cenników, budżetu, finansów ani checklist.

      Dokumenty / oferty

      Magazyn plików: dokumenty trzymaj w prywatnym folderze Google Drive, a w panelu zapisuj link, opis, kategorię i powiązanego klienta.

      Panel nie wrzuca PDF/DOCX/XLSX do GitHub ani na Vercel.

      Przy uploadzie i synchronizacji panel sugeruje kategorie po nazwie pliku: cenniki, umowy, oferty, formalne, ARiMR, materiały, BRUNIMAT, pawilony i klienci.

      Otwórz folder Drive
      Pliki wrzucone do firmowego folderu Google Drive pojawią się tutaj automatycznie. Panel pokaże podgląd i pobieranie, jeśli Google Drive pozwala na dostęp.
      Możesz też wybrać plik tutaj: panel wyśle go do Google Drive i od razu zapisze kartę dokumentu.
      Filtr „Do uporządkowania” pokazuje pliki bez opisu, bez linku, bez sensownej kategorii albo oferty/dokumenty klienta bez przypisanego klienta.

      Cenniki

      Prywatnie: cenniki i linki do plikow sa ladowane z prywatnego magazynu po zalogowaniu, a nie trzymane w zrodle HTML.
