      Backup danych panelu

      Prywatnie: Backup pobiera lokalną kopię danych panelu. Plik jest prywatny — nie wrzucaj go do repo ani nie wysyłaj osobom trzecim.
      Eksport nie zmienia danych i nie wysyła nic do JSONBin.

      Podgląd backupu JSON

      Uwaga: To jest tylko podgląd. Ten etap nie przywraca ani nie nadpisuje danych.

      Podgląd paczki importu danych

      Uwaga: To jest tylko podgląd paczki importu. Dane nie są zapisywane ani dopisywane do panelu.
      Ten szablon służy do przygotowania paczki danych do późniejszego podglądu/importu. Samo pobranie szablonu niczego nie zmienia w panelu.
